## Planner decisions recorded for this plan

- **Discretion — the table holds ONE command per platform arm, not a list.** The hint is an
  error-banner sentence, not documentation. D-13 stops at the install COMMAND and hands the fuller
  guidance to a later phase, and a single command per arm is what the frontend help panel can
  render as one monospace span. For the one provider with several first-party Windows routes, the
  PowerShell one-liner leads, because that is the form the vendor's own install block presents
  first.
- **Discretion — the wording.** The renderer composes the sentence from the existing display-name
  record plus the table's command, preserving today's suffix directing the user to the settings
  panel. That composition reproduces the three unchanged macOS/Linux hints character for character.
  It does change the Copilot sentence's product label from the hand-written one to the shared
  display name — a deliberate consequence of unifying on one source, on a string D-14 is replacing
  wholesale anyway. Record that in the commit and in a comment so a reviewer diffing the string
  does not read the label change as an accident.
- **The unknown-platform arm shows both commands only when they differ.** Three of the four
  providers install identically on both platforms, so duplicating the command there would be noise.
  Where the arms are equal the hint names one command; where they differ it names both, each
  labelled with its platform.
- **The Gemini package name keeps its assumption tag unless a documentation check clears it.**
  It was carried in from the shipping codebase and confirmed only against the registry. Registry
  existence is not verification — a slopsquatted package also resolves. T-06-16 requires one cheap
  first-party documentation check; if it confirms, the tag is upgraded and the source is cited; if
  it does not, the string stays exactly as it ships today and the tag stays. Either way, no string
  changes without a source.
