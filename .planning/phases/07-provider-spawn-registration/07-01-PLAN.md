<decisions_recorded>
Three open questions 07-RESEARCH.md left for the planner, resolved here with rationale. All three are
binding on 07-02..07-05.

**OQ-1 / A1 — single or double `^`-escaping for npm-global `.cmd` shims: MEASURE, do not guess.**
The module ships cross-spawn's own heuristic verbatim — double-escape only when the command matches
the `node_modules/.bin/*.cmd` shape, which for Drift's globally-installed targets means SINGLE
escaping — and task 2's `windows-latest` echo-shim test is the oracle. Task 2 asserts the round trip
under the shipped escaping AND asserts the opposite escaping does NOT round-trip, so a green run is
non-vacuous and a red one names the answer. Task 3 records the verdict with its run URL in the module
header. Rationale: research explicitly declined to guess, the test PRV-01 needs anyway answers it for
free, and shipping a guess here would corrupt every argument on the npm-global install path.

**OQ-2 — `${CAIDO_TOKEN}` reference for Gemini, not the literal token.** Recorded here because the
spawn env is this plan's surface; implemented in 07-03. Rationale, in order of weight:
(a) it keeps the token bytes out of `~/.gemini/settings.json`, a file OUTSIDE `%TEMP%` that
`sweepOrphanedMcpTempDirs` has never looked at and that survives a crash — the phase's headline
threat (T-07-03);
(b) it keeps the token bytes off the `mcp add` command line, invisible to a process listing (T-07-04);
(c) it sidesteps gemini's `--env` `split('=')` truncation defect entirely, so assumption A3 ("Caido
access tokens never contain `=`") stops being load-bearing (T-07-07);
(d) expansion resolves from gemini's UN-sanitized parent environment, which is exactly the environment
Drift controls through `buildSpawnEnv` at the provider launch site this plan wires;
(e) 05-D-10 rejected the shape when the expansion behaviour was UNCONFIRMED; it is now source-verified,
which is new information rather than a re-litigation. Its failure mode (a missing variable resolving
to the empty string, i.e. a silently unauthenticated server) is closed in 07-03 by a pure predicate
that refuses to register when the reference is used and the spawn env carries no non-empty token.
Codex gets the literal — no expansion exists there at all — and that trade is escalated to a
`checkpoint:decision` in 07-03 because it moves a live credential out of `%TEMP%`.

**OQ-3 — `getNodeExecutable`'s `--version` candidate loop (`index.ts:2737`) does NOT get the cmd.exe
plan; it keeps degrading gracefully.** Rationale: routing node itself through cmd.exe would add a
process-tree level to EVERY Drift MCP spawn, which is a direct cost to Phase 8's `taskkill /T /F`
work and to Phase 10's console-flash count, to buy the case of a user whose only node is a
`node.cmd` shim with no `node.exe` beside it. `buildSpawnPlan` is therefore applied at the CALL
SITES, never inside `spawnAndWait` — applying it inside the helper would silently capture site 3'
and the `where.exe` spawn too. 07-04 task 3 replaces the now-stale "deliberately absent" paragraph at
`spawnAndWait` with this decision so the comment stops contradicting the code.
</decisions_recorded>

    - POSIX passthrough is not a copy-by-reference trap: mutating the returned `args` must not mutate

      `windowsVerbatimArguments` false. This is Claude's native-installer path and the most common
      PRV-01 configuration.

    - win32 + `.cmd`: `file` is `cmd.exe`; `args` has exactly four elements, the first three being
      the `/d`, `/s`, `/c` switches in that order; the fourth begins and ends with a double quote;
      `windowsVerbatimArguments` true.
    - Case-insensitive extension match: an uppercase `.CMD` and an uppercase `.BAT` take the same
      branch as their lowercase forms.
    - Empty args array: the fourth element is the escaped command wrapped in the outer quote pair with
      NO trailing separator before the closing quote (edge probe: PRV-02 empty).
    - Ordering and stability: a five-argument list comes back in the same order, and two byte-identical
      arguments both survive in their original positions (edge probe: PRV-02 ordering).
    - Adjacency: an empty-string argument and a single-space argument each produce their own escaped
      element inside the command line and neither merges with a neighbour nor disappears (edge probe:

      string.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Drift backend -> `cmd.exe` argument parser | A command line assembled by Drift is re-parsed by a second interpreter under different rules. Every argument that crosses it is attacker-influenceable in the general case (paths carry the OS username; the prompt argument carries arbitrary user and target-application text). |
| Drift backend -> Windows process creation | The command-line string reaches `CreateProcess`; the runtime's own MSVC-convention quoting is deliberately disabled on this path. |
| Local machine registry -> `cmd.exe` startup | `cmd.exe` reads a per-user AutoRun key before executing the requested command. |
