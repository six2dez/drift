<objective>
Convert the provider launch to a direct spawn on every platform, delete the launch-script
indirection as one set, close RUN-04 structurally, and fence the surviving POSIX-only functions with
a dated deletion notice in both the code and the roadmap.

Purpose: `provider-launch-<sessionId>.sh` is the one generated script that literally cannot execute
on Windows, so Phase 7 cannot spawn a provider until it is gone. On POSIX the conversion is
behaviourally identical — the script only exported then exec'd, so child PID, pipes and effective
environment all match — which means the existing macOS/Linux suite exercises the new path in full.
That is the opposite of shipping Windows-only code no CI can reach.

Output: `index.ts` with one spawn per provider turn, `writeLaunchScript` gone, `withFsRetry` around
`writeTemp`, three dated deletion notices, and a ROADMAP whose SC-1 says what the code actually does.
</objective>
