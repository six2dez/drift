## Planner assumptions and no-silent-drop backstops

- Valid context means JSON parses to a non-null, non-array object. Full schema validation is intentionally not added because Zod/schema libraries crash QuickJS and the runtime context serializer already owns field shape.
- Readability is tested by opening/reading, not permission-bit inference; platform ACL semantics differ.
- T-08-93 and T-08-94 are allocated here and registered/audited by Plan 08-23.
- The unresolved LIF edge sets remain explicit from Plan 08-20; this plan closes the concrete reuse boundary only.

| Script path -> executable child | Health validation may read metadata but must never execute/import the script. |
