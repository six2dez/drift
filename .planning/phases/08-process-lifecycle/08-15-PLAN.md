<objective>
Make the two outstanding hardware measurements cheap and mechanical, so they get taken.

`08-VERIFICATION.md` calls one of them **"the cheapest high-value measurement in the phase: one
cancel and one glance"** — whether Caido's plugin sandbox can spawn the process enumerator at all.
If it cannot, the entire argv-marker orphan reap that plans 08-06/08-07 shipped is inert on the
shipping runtime while every gate stays green, which the phase named as its own largest risk in
ledger entries 14 and 15. Today that answer is only in the backend console. `08-UI-SPEC.md` decision
**UD-01** resolved this on 2026-08-28 — option C, a diagnostics-only key, no user-visible surface,
zero frontend files — and the key does not exist yet. This plan builds it.

The other measurement is the A1 re-run, and it is currently blocked on a probe that has to be
reconstructed by hand from a historical commit. Reconstruction by hand is how this phase produced
five wrong censuses and thirteen vacuous gates. So the fix ships as a committed patch file that
composes plan 08-12's tested helpers, and this plan proves the patch applies, type-checks and builds
before anyone is asked to run it.
