| Caido webview host storage -> frontend store | `window.localStorage` is host-controlled: it may be absent, throw on property access, or be a page-injected partial stub. Untrusted input crosses here. |
| Frontend store -> backend RPC `syncCaidoSessionToken` | The Caido session bearer token crosses this boundary; an empty value is the authentication-refused signal. |
